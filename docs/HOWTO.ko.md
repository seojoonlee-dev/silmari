# Silmari 사용 안내

Silmari(실마리)는 화면을 지켜보고 대신 기억해 주는 도구입니다. 무엇이 열려 있었는지, 무엇을 하고
있었는지, 무엇을 하다 말았는지를 타임라인으로 보여주고, 하루에 대해 질문하면 실제 스크린샷을 읽고
답합니다. 모든 데이터는 주최자의 서버에만 저장되고 외부로 나가지 않습니다.

## 1. 접속

- 주소: **주최자가 알려준 주소** (행사장 슬라이드 참고)
- 비밀번호: **주최자가 알려준 비밀번호**
- 브라우저: Chrome, Edge, Firefox, Safari 모두 됩니다. 노트북 화면이 넓을수록 보기 좋습니다.

비밀번호는 한 번만 입력하면 그 브라우저는 계속 로그인 상태로 남습니다. 처음 들어가면 1분짜리
사용법 안내가 자동으로 나옵니다. 건너뛰어도 되고, 나중에 오른쪽 위 **시간**을 눌러 나오는 메뉴의
**사용법 다시 보기**로 다시 볼 수 있습니다.

## 2. 녹화 시작

1. 오른쪽 위 **녹화 시작** 버튼을 누릅니다.
2. 브라우저의 화면 공유 창에서 **전체 화면**을 고릅니다. 창 하나만 고르면 그 창만 기록됩니다.
3. 3초마다 한 프레임이 서버로 전송됩니다. 버튼에 프레임 수가 올라가면 정상입니다.

운영체제별 참고:

- **macOS**: 처음 한 번 브라우저에 **화면 기록** 권한을 줘야 합니다. 시스템 설정 → 개인정보 보호 및
  보안 → 화면 기록에서 브라우저를 켠 뒤 브라우저를 다시 실행하세요.
- **Windows**: 별도 설정이 없습니다. 공유 창에서 "전체 화면"을 고르면 됩니다.
- **Linux**: Wayland에서는 포털 창이 뜹니다. 모니터를 고르세요.

녹화를 멈추려면 같은 버튼(녹화 중 · N 프레임)을 다시 누르거나 브라우저의 공유 중지를 누릅니다.
페이지를 새로고침하면 녹화가 멈추므로 다시 시작 버튼을 눌러야 합니다.

## 3. 화면 구성

- **왼쪽 위, 화면 미리보기**: 녹화 중에는 실시간 화면이 보입니다. 모델이 인식한 창마다 색 테두리가
  그려지고, 테두리에 마우스를 올리면 그 창의 내용 요약이 따라다닙니다. 타임라인을 탐색 중일 때는
  그 순간의 스크린샷이 보입니다.
- **왼쪽 아래, 화면에 표시 중**: 그 순간 화면에 있던 창 목록입니다. 하나를 클릭하면 요약이 펼쳐집니다.
  같은 앱의 창 두 개도 내용으로 구분됩니다(예: 브라우저 창 3개).
- **오른쪽, 서술**: 현재 구간에 대한 짧은 이야기입니다. 파일 이름, 페이지, 음악, 명령어, 사람 이름을
  실제 화면에서 읽어 씁니다. 아래 **남겨둔 것**에는 하다 만 일(보내지 않은 답장, 저장 안 한 편집,
  아직 돌고 있는 명령)과 닫아버린 알림이 나옵니다.
- **아래, 타임라인**: 창마다 한 줄이고, 화면에 보였던 동안만 그려집니다. 다른 작업 공간으로 옮기면
  줄이 끊기고, 돌아오면 이어집니다.

## 4. 하루 되감기

- 타임라인 위에 **마우스를 올리면** 그 순간으로 탐색됩니다. 미리보기, 창 목록, 서술이 모두 그 순간
  기준으로 바뀝니다.
- **클릭하면 고정**됩니다. 고정된 핀은 검은 선과 고리 모양 손잡이로 표시됩니다.
- 타임라인 끝(지금)을 클릭하거나 오른쪽 위 **지금으로** 버튼을 누르면 실시간으로 돌아옵니다.
- 아래 **카드**는 같은 창들이 화면에 있던 하나의 구간입니다. 마우스를 올리면 요약 카드가, 클릭하면
  전체 이야기와 **이 순간으로 이동** 버튼이 있는 창이 열립니다.

## 5. 질문하기

오른쪽 아래 입력창에 무엇이든 물어보세요.

- "터미널에 뭐라고 나왔지?"
- "아까 읽던 논문 제목이 뭐였지?"
- "무슨 노래가 나오고 있었어?"
- "하다 만 게 뭐 있지?"

답변은 실제 스크린샷을 읽어서 씁니다. 답변에 나오는 **시각**은 버튼이 되어 누르면 그 순간으로
이동합니다. 입력창 위의 칩은 여러분의 활동에서 제안된 질문이므로 눌러보기만 해도 됩니다. 대화는
저장되어 새로고침해도 남고, 이어지는 질문("그 노래 가수는?")도 앞 대화를 기억합니다. 타임라인을
탐색 중일 때 질문하면 그 순간을 기준으로 답합니다.

## 6. 알림

화면에 뜬 알림(Slack, Gmail 등)은 시각과 함께 기록되고, 닫히면 "닫음"으로 표시됩니다. 서술의
**남겨둔 것**과 카드 요약에서 볼 수 있어, 무심코 닫아버린 알림을 나중에 찾을 수 있습니다.

## 7. 메뉴 (오른쪽 위 시간 클릭)

- **언어**: EN / 한국어. 화면 글자뿐 아니라 모델의 서술, 질문 제안, 답변도 그 언어로 바뀝니다.
  바꾸면 기존 서술을 그 언어로 다시 쓰는 데 잠시 걸립니다.
- **사용법 다시 보기**: 처음의 안내를 다시 봅니다.
- **내 데이터 초기화**: 이 브라우저가 기록한 스크린샷과 기억을 서버에서 모두 삭제합니다. 다른
  사람의 기록에는 영향이 없습니다.
- **로그아웃**: 비밀번호를 다시 묻게 됩니다.

## 8. 알아두면 좋은 것

- 브라우저마다 별도의 기록입니다. 같은 노트북이라도 다른 브라우저로 접속하면 새 기록이 시작됩니다.
- 화면이 바뀌면 바로, 그렇지 않으면 15초마다 모델이 화면을 읽습니다. 창 목록과 테두리가 실제 화면보다
  몇 초 늦을 수 있습니다.
- 작업 공간(가상 데스크톱)을 빠르게 넘기는 동안의 애니메이션 프레임은 건너뜁니다.
- 스크린샷은 24시간 뒤 자동으로 삭제됩니다.
- 여러 사람이 동시에 써도 각자의 기록은 서로 보이지 않습니다.

## 9. 문제가 생기면

- **녹화 시작을 눌러도 아무 일이 없다**: 공유 창에서 취소했거나(다시 누르면 됩니다) macOS의 화면
  기록 권한이 없는 경우입니다.
- **창 목록이 비어 있다**: 첫 분석까지 10초 정도 걸립니다. 계속 비어 있으면 화면 공유가 "창 하나"로
  되어 있지 않은지 확인하세요.
- **미리보기가 검다**: 녹화 중이 아닙니다. 녹화 시작을 누르세요.
- **답변이 엉뚱하다**: 타임라인에서 관련 순간을 클릭해 고정한 뒤 다시 물어보면 그 순간의 스크린샷을
  읽습니다.
